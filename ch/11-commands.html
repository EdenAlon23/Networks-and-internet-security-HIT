Exam trap

Order matters: rules are checked top to bottom and the first match wins. If you set the INPUT policy to DROP over SSH before adding the ACCEPT rule, you lock yourself out.

9What each attack looks like on the wire

The defender's cheat sheet: for each attack in the course, the pattern in a capture and the defense. This is also how exam questions are often phrased ("given this capture, what is happening?").

AttackPattern in the captureDefenseChapter
Ping sweep / ARP scanEcho requests or ARP who-has to every address in a subnet, in orderRate alerts (IDS), block ICMP at the edge03
SYN scanOne source, SYNs to many ports; SYN/ACK answered by RST, never by ACKIDS threshold rules, close unused ports03
Idle scanTarget sees SYNs "from" a quiet third host; that host's IP ID rises by 2Random IP IDs, egress filtering03
MAC floodingThousands of frames with random source MACs per secondPort security04
ARP poisoningUnsolicited ARP replies; the gateway's IP suddenly maps to a new MAC; duplicate IP warningsDynamic ARP Inspection, static ARP, arpwatch04
Rogue DHCP / starvationTwo different servers sending Offers; hundreds of Discovers with random MACsDHCP snooping (trusted ports)04
DNS poisoning (Kaminsky)Queries for random subdomains; a flood of responses with varying IDs before the real oneSource-port randomization, DNSSEC04
SYN floodHuge rate of SYNs from many (spoofed) sources, few or no final ACKsSYN cookies, rate limits, upstream scrubbing05
RST injectionA RST in the middle of a session from the right 4-tuple, often with a TTL different from the peer'sStrict in-window checks (RFC 5961), encryption with integrity (TLS/IPsec)05
Smurf / amplificationVictim receives many replies (ICMP, DNS, NTP) it never asked for; small requests, large responsesNo directed broadcast, BCP 38, no open resolvers05
Teardrop / bad fragmentsOverlapping fragment offsets, or reassembled size > 65,535Patched stacks, firewalls that reassemble05
Mail spoofingFrom: domain does not match SPF/DKIM results in the headers (Authentication-Results)SPF, DKIM, DMARC p=reject08

10Review

Which Wireshark filter finds a NULL scan?

tcp.flags == 0x000

Which iptables option makes a rule stateful?

-m conntrack --ctstate ESTABLISHED,RELATED

How do you verify an openssl signature?

openssl dgst -sha256 -verify pub.pem -signature sig.bin file

In a capture, many SYNs from different sources and almost no ACKs. What is it and what is the defense?

A SYN flood (spoofed sources). SYN cookies and rate limiting.
