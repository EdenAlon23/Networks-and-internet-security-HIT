2Using the site in class

  • Animations as live demos. Every animation steps one packet at a time with the exact header fields. Pause on a step and ask "what will the reply be?" before pressing next. Use the speed control (0.5×) on a projector.
  • Quiz as a warm-up or exit ticket. Each chapter ends with a short quiz (shuffled, with explanations). The practice page builds a mixed set from any chapter or a whole course.
  • Worked examples. The calculation chapters (N02, N03, N05, N06, N07, N08, N09, N10) contain step-by-step solutions in exam format; N11 collects eight patterns on one page.
  • Lab sessions. N12 has one hands-on exercise per networks chapter; chapter 11 has the security lab commands and what each attack looks like in Wireshark.
  • Both languages. The 🌐 button switches English/Hebrew; links to a section work in both, so a link sent to students opens in each student's chosen language.

6About this material

The site was written by a student as a study aid. It follows the course lectures and the standard textbooks (Kurose and Ross for networks), but it is not official course material. Where the site goes beyond the slides, it says so. If a lecturer finds an error or wants a topic emphasized differently, the source is open on GitHub and corrections are welcome.
